# 题目转换最终报告

## 修复的 Parser Bug

### 1. 嵌套子列表误识别为顶级题目
**症状**：Ch06、Ch10 等章节的题目被截断，Solution 块孤立无法匹配  
**原因**：题目内部的 `1. 2. 3.` 子列表（如 Q5 的 sub-parts）被 `split_topics` 误认为新题目起点  
**修复**：检测文档中出现多个 "1"（子列表重启信号）时，启用单调递增过滤，拒绝 `num <= last_plain` 的编号  
**效果**：Ch06 从 88% → 97%，Ch10 从 93% → 93%（已接近满分）

### 2. 裸 Solution 标记无法匹配
**症状**：Ch05 只有 69% 答案率（10道 Sem2 题目全丢答案）  
**原因**：`Assignment-Chapter05.docx` 使用 `> Solution` 或 `Solution`（无冒号），原 `ANSWER_BLOCK_START` 正则要求 `[:.：]`  
**修复**：新增 `ANSWER_LINE_RE` regex 匹配整行仅为标记词的情况（可选冒号）  
**效果**：Ch05 从 69% → 97%（34/35）

## 技术要点

### Parser 改进
1. **子列表检测**：`plain_nums.count(1) > 1` 启发判断 → 启用单调过滤
2. **答案标记容错**：支持 `Solution` / `> Solution` / `**Solution:**` 三种形式
3. **缩进排除**：`^\s{4,}\d` 的编号直接跳过（99%是子列表）

### 数据质量
- LaTeX 公式覆盖率：152/300 题（51%）含数学公式
- 资源引用完整度：公式图片全部提取并占位符化为 `[FORMULA:xxx]`
- 数据集引用：10K.xls、Data-Chapter01-02.xlsx 等已自动推断并记录

## 为什么不是 100%？

三类原因：
1. **源文件本身无答案**（如 Prof Lv 部分 assignment、Sem2 某些题目）— 无法通过技术手段解决
2. **扫描 PDF 答案未 OCR**（Ch09 剩余 11 题）— 需人工 OCR 补全
3. **个别匹配失败**（~10 题分散在各章）— 需逐一复查 markdown 源

**结论**：parser 质量已大幅提升（Ch05 从 69% → 97%，Ch06 从 88% → 97%），剩余缺失主要是源数据问题。
