# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch and to the
currently deployed Cloudflare Pages build. Older commits and local snapshots
are not supported release lines.

## Reporting a vulnerability

Please use the repository's **Security** tab and choose **Report a
vulnerability**. If private vulnerability reporting is unavailable, contact
the repository owner privately before opening a public issue. Include the
affected URL or component, reproduction steps, impact, and any suggested
mitigation.

Do not include live credentials, session tokens, personal data, or database
exports in a report. Revoke or rotate any credential that may have been
exposed. We will acknowledge a complete report as soon as practical and will
coordinate disclosure after a fix is available.
