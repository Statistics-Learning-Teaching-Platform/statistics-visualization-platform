### 工具需求

如果需要重新运行转换或验证，需要安装：

1. **LibreOffice**
   - 用途: .doc → .docx 转换
   - 安装: `choco install libreoffice` (Windows) 或从官网下载
   - 确保 `soffice` 命令在PATH中

2. **Pandoc**
   - 用途: .docx → markdown 转换（保留公式和图片）
   - 安装: `choco install pandoc` (Windows) 或从官网下载
   - 确保 `pandoc` 命令在PATH中

3. **Python依赖**（如果需要运行build_dataset.py）
   - 基础库应该已经满足
   - 如果Word COM回退方案需要lxml: `pip install lxml`
