# Assignment 9 — Question 1

## Problem
In recent years the interest rate on home mortgages has declined to less than 6.0 percent. However, according to a study by the Federal Reserve Board the rate charged on credit card debt is more than 14 percent. Listed below is the interest rate charged on a sample of 10 credit cards.

| | | | | | | | | | |
|---|---|---|---|---|---|---|---|---|---|
| 14.6 | 16.7 | 17.4 | 17.0 | 17.8 | 15.4 | 13.1 | 15.8 | 14.3 | 14.5 |

Is it reasonable to conclude the mean rate charged is greater than 14 percent? Use the 0.01 significance level.

## Solution

**Sample statistics**

$$\bar{X} = \frac{14.6 + 16.7 + \cdots + 14.5}{10} = \frac{156.6}{10} = 15.66$$

$$S = \sqrt{\frac{\sum (X_i - \bar{X})^2}{n-1}} = \sqrt{\frac{(14.6-15.66)^2 + (16.7-15.66)^2 + \cdots + (14.5-15.66)^2}{9}} = \sqrt{\frac{21.444}{9}} \approx 1.54$$

**1. Hypotheses**

$$H_0: \mu \le 14 \quad \text{versus} \quad H_a: \mu > 14$$

**2. Significance level**

$$\alpha = 0.01, \quad n = 10$$

**3. Test type**

This is a one-sample *t* test (population standard deviation unknown), with $df = n - 1 = 9$.

**4. Critical value**

For $\alpha = 0.01$ (one-tailed, right side), the critical *t* value is $2.821$.

**5. Test statistic**

$$t = \frac{\bar{X} - \mu}{S/\sqrt{n}} = \frac{15.66 - 14}{1.54/\sqrt{10}} = 3.409$$

**6. Decision and conclusion**

Since $t = 3.409 > 2.821$, reject $H_0$ at the 0.01 level.

It is reasonable to conclude the mean rate charged is greater than 14 percent.
